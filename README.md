# Hidjaz Knowledge Base

База знаний о Коранах и архив контента Instagram @hidjaz.premium.

## Цели
- Сохранить оригиналы видео, фотографий, каруселей и подписей к публикациям.
- Подготовить проверенный каталог товаров и ответы для команды продаж.
- В дальнейшем подключить структурированные материалы к KnowledgeHub.

## Хранение
- GitHub: инструкции, манифесты, метаданные, каталог, расшифровки и история изменений.
- Cloudflare R2 (планируется): оригинальные MP4/JPG и другие крупные медиафайлы.
- Supabase (планируется): индекс публикаций и поисковые данные. Не изменять существующие таблицы KnowledgeHub без отдельной проверки.

## Состояние
- В Apify получено 45 записей Instagram; данные необходимо импортировать из оригинального JSON и проверить.
- Медиафайлы ещё не загружены в постоянное хранилище.
- Временные URL Instagram нельзя считать надёжным архивом.

## Принципы
1. Оригиналы не изменять; производные данные хранить отдельно.
2. Для каждого объекта сохранять URL публикации, тип, подпись, дату и идентификатор.
3. Не размещать секреты, токены и личные данные в репозитории.
4. Проверять целостность медиа по SHA-256 после загрузки.
5. Не утверждать, что архив полон, пока не сверено количество публикаций.
